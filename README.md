# 🐾 PetHero – Sistema Integrado de Resgate e Adoção

> **Status do Projeto:** ⚠️ Funcional / Em Desenvolvimento (Projeto Acadêmico)

## 📋 Descrição do Projeto
O **PetHero** é uma plataforma web desenvolvida para centralizar o reporte de animais em situação de risco e facilitar o processo de adoção responsável. O sistema conecta a comunidade, protetores independentes e ONGs, permitindo que resgates sejam feitos com maior agilidade através de geolocalização e que animais encontrem novos lares através de um catálogo digital intuitivo.

---

## 🎓 Contexto Acadêmico
Este projeto está sendo desenvolvido como parte da avaliação prática da disciplina de Padrões de Projeto de Software, no curso de Tecnologia em Sistemas para Internet, no Instituto Federal de Educação, Ciência e Tecnologia da Paraíba, Campus Picuí.

O objetivo desta atividade é demonstrar competências em:
* Desenvolvimento Fullstack (Frontend e Backend).
* Documentação e versionamento de software.

---

## 🚀 Funcionalidades Implementadas

### 👤 Área do Usuário (Público)
* **🐕 Catálogo Dinâmico:** Visualização de pets disponíveis com filtros inteligentes por espécie (Cachorro/Gato) e idade (Filhotes/Idosos).
* **📍 Reporte Detalhado:** Formulário de denúncia com campos de localização, descrição e dados de contato.
* **❤️ Apoio à Causa:** Módulos integrados para **Doação** e **Voluntariado**.
* **🔐 Acesso Seguro:** Sistema de Cadastro, Login e Recuperação de Senha.

### 🛠️ Painel do Protetor (Administrativo)
* **📊 Dashboard Estatístico:** Cards de resumo com contagem total de pets, animais disponíveis, adotados e pedidos pendentes.
* **✅ Gestão de Adoção:** Controle de pedidos de interessados, permitindo marcar como "Concluído" ou reabrir processos ("Undo").
* **🔄 Controle de Status:** Sistema de um clique para alterar o status do animal entre **Disponível** (Verde) e **Adotado** (Roxo).
* **💬 Central de Mensagens:** Visualização rápida de contatos de interessados diretamente no painel.
* **👤 Perfil do Protetor:** Página dedicada com biografia e estatísticas de "Vidas Salvas".

## 🛠️ Tecnologias Utilizadas

Para garantir robustez e agilidade, as seguintes tecnologias foram escolhidas:

* **Backend:** [Python](https://www.python.org/) + [Flask](https://flask.palletsprojects.com/)
* **Banco de Dados:** [SQLAlchemy](https://www.sqlalchemy.org/) + SQLite (ORM para gestão de dados relacionais)
* **Frontend:** HTML5 + [Tailwind CSS](https://tailwindcss.com/)
* **Ícones e Fontes:** Material Symbols Outlined + Plus Jakarta Sans
* **Template Engine:** Jinja2
